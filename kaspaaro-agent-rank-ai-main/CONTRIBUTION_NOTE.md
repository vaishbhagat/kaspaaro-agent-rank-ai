# Contribution Note

## Project Overview
AgentRank AI is an AI Commerce Readiness Analyzer for Shopify merchants that evaluates how AI shopping agents (ChatGPT, Gemini, Perplexity, etc.) perceive and recommend a store. It provides insights on product content quality, policy clarity, trust signals, metadata, and overall AI discoverability readiness.

## Contribution Summary
