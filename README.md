# AgentRank AI

## AI Commerce Readiness Analyzer for Shopify Stores

AgentRank AI is a SaaS-style web application that helps Shopify merchants understand how AI systems like ChatGPT, Gemini, and Perplexity perceive their store and products.

It analyzes product content, policies, FAQs, trust signals, and metadata to generate an AI Commerce Readiness Score along with improvement recommendations.

## Problem Statement

Most Shopify stores are not optimized for AI-based product discovery. This leads to:

- Poor visibility in AI search results
- Weak trust signals
- Incomplete product descriptions
- Missing or unclear policies and FAQs
- Poor metadata quality

Merchants currently have no clear way to understand how AI systems interpret their store.

## Solution

AgentRank AI provides a structured analysis of a Shopify store by:

- Evaluating product descriptions, policies, FAQs, and metadata
- Measuring trust and clarity signals
- Generating an AI readiness score
- Identifying critical issues
- Providing actionable recommendations to improve AI visibility

## Features

- AI Commerce Readiness Dashboard
- Store connection input page
- AI scan loading simulation
- AI readiness score breakdown
- Product optimization suggestions
- Policy analysis (shipping and returns)
- Before vs after improvement insights

## How to Run Locally

1. Clone the repository
   git clone https://github.com/your-username/AgentRank-AI.git

2. Move into the project folder
   cd kaspaaro-agent-rank-ai-main

3. Install dependencies
   npm install

4. Run the development server
   npm run dev

5. Open in browser
   http://localhost:3000
